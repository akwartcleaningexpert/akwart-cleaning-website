# A-Kwart Cleaning Expert

This repository contains the static website for A-Kwart Cleaning Expert, a professional cleaning company serving homes and businesses.

## Project overview

The website is built as a simple static landing page using HTML and CSS. It includes:

- A welcoming hero section
- Service highlights
- About section
- Contact/CTA section
- Clean responsive layout for desktop and mobile

## Files

- `index.html` – main landing page for the website

## Local preview

Open `index.html` in a browser to view the site locally.

## Contact

For quotes or inquiries, use the contact email listed on the page or reach out via the business contact details provided in the website content.
